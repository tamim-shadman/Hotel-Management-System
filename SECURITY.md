# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 2.7.x | ✅ Yes |
| < 2.0 | ❌ No |

---

## Reporting a Vulnerability

We take the security of Aura Grand PMS seriously. If you discover a security vulnerability, please follow responsible disclosure guidelines:

1. **Do not create public GitHub issues** for security vulnerabilities.
2. Email the lead maintainers directly at `admin@auragrand.com`.
3. Provide detailed steps to reproduce the issue, including environment and payload specifics.
4. Maintain confidentiality until a patch has been published.

### Security Commitments
- Acknowledge reports within 24 hours.
- Provide a patch or mitigation timeline within 72 hours.
- Credit the discoverer in release notes upon publication.
