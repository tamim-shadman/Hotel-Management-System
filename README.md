## About the Project

The Hotel Management System is a framework within which all aspects of the proper management of an ideal hotel are carried out. These aspects involve managing information about the various customer services, room services and facilities, staffs, managers, customers, bookings, checkout facilities, billing, and other services.

This system provides an efficient way of managing the hotel service system. It allows customers to choose their desired options efficiently, including selecting preferred rooms, making bookings, checking out, and handling billing.

The first activity of this project starts with a welcome page along with the options of viewing hotel services, admin login, and user login:

- **Admin Login** – Managed and used by hotel authorities to handle staff and customer information, hotel changes, and money transactions.
- **User Login** – Managed by hotel authorities but used by customers to browse hotel services, book rooms, and check out.

## Features

### Admin Dashboard
- **Employee Management** – Add, update, and manage hotel staff records
- **Customer Management** – Manage customer information and history
- **Billing** – Handle money transactions and generate invoices

### User Dashboard
- **Room Selection** – Browse and select from available room types
- **Vacant Rooms** – View real-time room availability
- **Other Services** – Access additional hotel amenities and services
- **Booking** – Reserve rooms and services
- **Checkout** – Process checkouts and finalize billing

### General
- **Sign Up and Login** – Secure authentication for both admins and customers
